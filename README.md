# Life Stream

A web application aimed to provide service to a blood bank where donors can gather info and manage their profile and agents can manage clients and maintain contract with donors. It is an academic project that reflects only the topics learned throughout the course.

## Features

1. Authentication
2. Amazing design
3. User friendly UI
4. Manage clients smoothly


## Tech stack

### Frontend
1. HTML
2. CSS
3. Javascript

### Backend
1. PHP
2. MySQL
